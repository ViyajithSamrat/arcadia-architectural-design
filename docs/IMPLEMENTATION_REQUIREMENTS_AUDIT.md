## How a row is classified

| Classification | Meaning |
|---|---|
| VERIFIED | Implemented; automated tests exercise the real logic and pass; and the behaviour has been seen working on the local stack (live suites and/or a real browser). Anything that depends on a real provider counts only if it has run against that provider. |
| IMPLEMENTED, NOT FULLY VERIFIED | Implemented and tested, but a required kind of evidence is missing: a real-provider run, a browser run on the current build, or real failure conditions. |
| BLOCKED (EXTERNAL) | The main behaviour cannot be shown without something only the owner can supply (here: an active Gnani key). |
| NOT IMPLEMENTED (PARTLY) | Part of the requirement's text is not built. |

A passing test count is never used as proof of a requirement the tests do not exercise. Nothing here claims a hosted deployment or a working Google sign-in.

## What changed since the 2026-10-22 audit

That audit counted 26 of 35 (74%) complete. Under the stricter rule above the count is 28 (80.0%), for these reasons:

- Downgraded: PR-005 (only the labelled mock transcriber has ever produced a transcript) and PR-032 (no live image job has been written through the app).
- Newly verified: PR-002 (360 px run), PR-006 (real OpenRouter briefs through the app), PR-010 (real local Storage and a browser run), PR-023 (release exercised in a browser with invalid attempts refused).
- Gap closed this pass: PR-016 had no Download control although the requirement says "view/download"; a Download link was added and checked. PR-015's empty state is now checked in a browser.
- Still open: PR-004 and PR-009 are blocked on an inactive Gnani key; PR-024 lacks discounts, add-on rates, scheduled dates and an editor for payment instructions (owner decisions); PR-033 and PR-034 await real provider failures and a working Gnani path.
