# 9. Five-Minute Demo Script

1.  **Landing page (30 sec):** Explain three services and choose "New
    Build on Empty Plot."
2.  **Voice and brief (60 sec):** Record a short request in a configured
    language, show transcript, correct a room count, review the English
    brief.
3.  **2D schematic and concept images (60 sec):** Show labelled SVG
    schematic and generated static concept image; explain concept-only
    limitation. These are static images, not an interactive or
    dimensionally accurate 3D model.
4.  **Interior or landscape (45 sec):** Upload safe sample room/garden
    image and generate a concept through the same adapter.
5.  **Pricing and payment (60 sec):** Show itemized quote, configured
    transfer instructions, and payment-reference/proof submission; show
    pending status.
6.  **Admin verification and release (60 sec):** Verify a controlled
    test transfer or clearly labelled demo fixture; preview and release
    results; return to customer view and open results.
7.  **Security and limits (25 sec):** Demonstrate denied
    unpaid-generation API test and explain outputs are not
    CAD/construction drawings.

Use only authorized test transfers or clearly labelled fixtures. Never
fabricate a real payment verification.
